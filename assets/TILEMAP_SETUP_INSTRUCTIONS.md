# Инструкция по настройке TileMapLayer в Godot 4.7

## Шаг 1: Откройте сцену MainScene.tscn

1. В Godot Editor откройте `res://scenes/MainScene.tscn`
2. Выделите узел `TileMapLayer` в панели сцены (слева)

## Шаг 2: Создайте и настройте TileSet

1. В Inspector (справа) найдите свойство **Tile Set**
2. Нажмите **[New TileSet]** (если ещё не создан)
3. Разверните раздел **TileSet** (нажмите на стрелку)

## Шаг 3: Добавьте текстуры тайлов

### Добавление пола (empty_tile.png):
1. В разделе **TileSet** найдите **Tiles** → нажмите **+ (Add)** 
2. Перетащите `res://assets/empty_tile.png` из FileSystem в появившееся поле Texture
3. Убедитесь, что размер тайла установлен в **16x16** (TileSet → Tile Size)

### Добавление стен (wall.png):
1. Снова нажмите **+ (Add)** в разделе Tiles
2. Перетащите `res://assets/wall.png`
3. Размер также должен быть 16x16

## Шаг 4: Настройте отступы (Separation/Padding)

Для каждого тайла (пол и стены):

1. Выделите тайл в списке **Tiles**
2. Найдите раздел **Texture Region** или **Padding**
3. Установите:
   - **Margin** = 1 (внешний отступ)
   - **Separation** = 1 (расстояние между тайлами)

Или в некоторых версиях Godot:
- В **TileSet** → **Physics Layers** → выберите слой
- Для каждого тайла установите **Texture Padding** = 1

## Шаг 5: Настройте Custom Data для стен (для коллизий)

Чтобы скрипт игрока распознавал стены:

1. В **TileSet** найдите раздел **Custom Data Layers**
2. Нажмите **+ (Add)** → выберите **String**
3. Назовите слой `type`
4. Теперь для каждого тайла стены:
   - Выделите тайл стены в списке
   - Найдите раздел **Custom Data**
   - В поле `type` напишите: `wall`
5. Для пола можно оставить пустым или написать `floor`

## Шаг 6: Нарисуйте уровень

1. Выберите узел `TileMapLayer`
2. На верхней панели редактора появится панель рисования тайлов
3. Выберите тайл пола и закрасьте область уровня
4. Выберите тайл стены и нарисуйте границы уровня

## Шаг 7: Проверка работы

1. Запустите сцену (F5 или кнопка Play)
2. Игрок должен:
   - Двигаться на WASD/стрелки по полу
   - **Не проходить** через тайлы стен (с custom data type="wall")
   - Останавливаться перед стенами

---

## Альтернативный способ (через Bitmask)

Если Custom Data не работает, можно использовать Bitmask:

1. В **TileSet** → **Layers** добавьте **Physics Layer**
2. Для тайлов стены включите бит коллизии (Bit 0)
3. В скрипте игрока измените проверку на использование `get_cell_source_id()` и проверки физики

Но рекомендуется использовать **Custom Data**, так как это более гибкий подход для roguelike.
